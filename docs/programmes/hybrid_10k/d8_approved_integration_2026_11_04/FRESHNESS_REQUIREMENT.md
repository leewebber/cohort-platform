# Approved 5K freshness and renewal requirement

Founder-approved against the complete e676e31 source, 4 November 2026.

> Accept that this programme requires eligible 5K evidence at each new 5K-targeted start. Athletes may replace their input with a genuinely completed, representative sustained 5K, then explicitly confirm, review and accept the resulting targets. If eligible evidence is unavailable, affected starts remain unavailable. Preserve the 56-day rule, existing threshold-only manual alternative and frozen started sessions. Add no test or fallback.

Eligibility remains **0 through 56 local civil days inclusive**, checked at the actual new occurrence start in the confirmed training/assignment IANA timezone. Programme entry or an earlier review cannot reserve later eligibility. A genuinely started occurrence retains its original frozen target snapshot. The existing rule, formulas, rounding and source-selection/acceptance behaviour are unchanged; this requirement neither deploys the held implementation nor grants hosted authority.

The exact affected inventory is [recorded here](FRESHNESS_REQUIREMENT.json): all ten Tuesdays plus W6–9 Fridays. W1–5 threshold Tuesdays retain the existing explicitly selected manual-threshold alternative. W6–10 10K-specific Tuesdays and W6–9 short-5K Fridays require eligible 5K evidence; the source has no scalar authored-RPE fallback. Strength, Zone 2 work, relaxed strides and the final measured 10K have no 5K-freshness dependency; their other requirements remain unchanged.

For the illustrative source calendar, a genuine result dated 2 November 2026 is eligible through 28 December inclusive. Without newer evidence, W9 Tuesday (29 December), W9 Friday (1 January) and W10 Tuesday (5 January) become unavailable for new starts. Older inputs can lose eligibility earlier. One later genuine result dated 10 November or later, already available and accepted before the first affected start on 29 December, could cover those remaining quality sessions through 5 January. Actual delays/rescheduling require evaluation on the actual start date. This is a conditional example, not an athlete record, scheduled assessment or promise of continuous availability.

A new result must actually exist: no future date, fabricated evidence, required inserted test, silent reuse after expiry, input auto-ingestion, substituted target family or invented fallback. If no eligible evidence or applicable existing threshold alternative is selected, the affected new start remains unavailable. Renewal changes future starts only after explicit review/acceptance.
