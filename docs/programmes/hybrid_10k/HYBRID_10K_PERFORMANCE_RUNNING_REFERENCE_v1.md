Use the existing approved M2.3 rules and athlete acceptance behaviour:
- Threshold-labelled work: approved 5K-derived threshold window, or

- 5K work: approved short-5K pace window.
- Zone 2: athlete-confirmed numerical heart-rate range.
- Warm-ups/recoveries/cooldowns: authored easy effort, not invented pace.
- Accelerations: relaxed and controlled, not sprints.

COMMON TUESDAY STRUCTURE — ALL TEN WEEKS
Warm-up:
- 600 seconds easy running.
- Three repetitions of:
20 seconds relaxed acceleration.
40 seconds very easy running.
Total warm-up: 780 seconds / 13 minutes.
Main set: per weekly table.
Recoveries occur BETWEEN work repetitions only.
There is no recovery after the final work repetition.
Cooldown:
- 300 seconds / 5 minutes very easy running or walking.
