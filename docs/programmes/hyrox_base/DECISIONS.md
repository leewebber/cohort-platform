## Source completeness and independent technical delivery

All 48 main working prescriptions are complete and lower into existing canonical
session/runner models with additive typed fields. This is separate from authoritative
binding readiness: **zero real exact published version bundles are available**. Local
software authority fixtures prove lowering and round trips without becoming Base
exercise authority. The audit reports preparation, binding and capture limits alongside
source status for every session; a primary status never hides another category.

T2 (gym lowering) and T3 (main duration-choice handoff) are implemented locally.
Supersets, ranges, unilateral work, carries, holds, optional progression, minute work/
recovery/rest and exact source metadata survive lowering, save/reopen and source export.
A new source window stays distinct from the athlete's chosen duration; canonical start
freezes the choice and retry returns it. Prescribed duration is never an actual result.
The local migration and callable integration are not deployed.
