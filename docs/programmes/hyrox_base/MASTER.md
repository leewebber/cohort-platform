**Approved variants.** Exercise variant content is approved 2026-10-25: main front-rack reverse lunge uses a BARBELL front rack; cable Pallof press uses SPLIT STANCE. Preparation ramps remain separate from working sets. No RDL/lunge load derives from a squat benchmark.

**Audience.** Developing or advanced athletes able to run continuously for 45 minutes.

**Benchmarks.** 10 km run time, 2 km row time, back squat 5RM total external load, strict OHP 5RM total external load, maximum strict pull-ups (zero valid). Own test date and source/type required; no freshness cutoff or automatic latest/best selection.

**Capture.** Prescribed targets, advisory guidance and actual performance are separate. Athletes may record actual load in existing supported actual-load fields or optional notes; no new mandatory result, race attestation or division lookup follows from advisory text.

**Core progression.** Optional W5 carry load, longer plank lever or Pallof resistance only with position maintained and athlete choice. No compulsory increase. W4 carry and Pallof lighter.

**Core rest.** 45–60 seconds as needed; no compulsory recovery at each side change is prescribed.

**Duration.** Generally 60–90 minutes; do not add filler. Preparation and cooldown are additional to main running.

**Equipment.** Approved variants use barbell/rack (including front-rack reverse lunge), dumbbells/incline bench, pull-up bar, cable station (including split-stance Pallof), carry space, rower, fan bike, SkiErg, wall ball/target, kettlebell and preparation bands. Canonical identity/version authority and marketing/prerequisite copy are separate.

**Finisher load.** Effort/technique selected, no fixed kilograms. Rep work leaves recovery inside the minute; record athlete scaling using existing supported logging. “Use your race weight” in these circuits is advisory only: no exact load, target height, verified race standard or division lookup is prescribed. Explicit prescriptions and formal assessments retain their own requirements.

**History.** Explicit benchmark replacement acceptance affects future unstarted sessions only; started/completed prescriptions immutable. Actuals separate. No inferred loads for RDL/lunge/other press/pull-ups.

**Periodisation.** W1–3 build; W4 reduces gym/finisher demand with modest running reduction; W5–7 build; W8 consolidates.

**Personalisation.** Only quality running, dedicated rowing and back squat have approved numeric derivation. Pace=10 km seconds/10; 4–5 min x1.00–1.05, 6–7 min x1.02–1.07, 10 min x1.03–1.08. Row split=2 km seconds/4, +10–15 seconds for 2-min reps, +12–18 for 3-min reps; W4 +18–23, W8 +15–20. Squat=5RM x authored basis points/10000, nearest configured total barbell increment, ties down. No guessed increment. Missing means unavailable, plus authored effort only; no invented row fallback.

**Post base.** No compulsory post-Base assessment; representative benchmarks needed before next plan. Test Week is a separate unauthored programme, never inserted here.

**Purpose.** Build aerobic capacity, compound strength, shoulders/pulling, grip and bracing before specific HYROX preparation. Base is purpose, not beginner status.

**Running effort.** Easy/long conversational, RPE about 3–4. Quality RPE about 7, repeatable. Choose within duration windows by feel/recovery; no level bands or invented HR zones.

**Schedule.** Eight weeks; Mon Gym A, Tue easy run, Wed Gym B, Thu quality run, Fri Gym C, Sat long run, Sun rest. One session/day; six/week.

**Strength rest.** Back squat working sets: 150–180 seconds throughout; warm-up sets separate. RDL/reverse lunge: 120–180 seconds. Upper pair A: 90–120 seconds after pair; B/C: 90 seconds.

**Substitution.** Running intended for all three aerobic sessions. Bike substitution only under verified existing rules plus athlete acceptance, preserving duration/effort, never running pace. Approved variant content does not grant new substitution or canonical mapping authority.

**Upper progression.** Build repetitions within ranges before suggesting load increases; athlete accepts. No OHP load inference from its benchmark. No automatic progression on completion.
