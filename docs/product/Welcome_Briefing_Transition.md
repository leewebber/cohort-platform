## Constraints

| Constraint | Detail |
|------------|--------|
| Duration | Target under **1 second** when data is already available |
| Urgency | Never delay urgent app access for decorative animation |
| Repeat launches | Skip or compress on repeated launches |
| Accessibility | Honour reduced-motion setting |
| Hydration | Transition may mask genuine bootstrap hydration but must **not** fake loading |
| Visuals | No spinner, progress bar, or theatrical logo animation |
