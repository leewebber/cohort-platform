## Recommended allocation target

Allocate **transient synthetic composition of the accepted D1 programme editor
and D2 immutable strength-session catalogue**. A single synthetic v1 programme
should edit existing D1 metadata/week/day/required-slot fields and explicitly
choose exact frozen D2 revisions, then compile/export/review those two canonical
source lanes together. Retain D2's one straight-sets strength representation,
fixture exercise identities, immutable revision/source receipts and no-op rules;
do not add prescription types, programme families or authorable contracts.

The useful author flow would be: edit/freeze a synthetic session separately;
explicitly admit/select its sealed revision in the programme; edit the allowed
schedule/metadata; export complete Plan Package YAML plus exact sealed Founder
sources; refresh actual Studio from those same bytes. Source digest/tuple and
body-excluding package hash remain distinct. Editing either lane must invalidate
its affected current export/review; no automatic reference upgrades or catalogue
replacement. Locked progression/adaptation/invariant/assessment/evidence/
comparison contracts remain equal to their original authored values.

- Inspect D1 trusted catalogue/reference checks, D2 source-bound frozen entries
  and `SyntheticStrengthReviewBridge`. Define explicit catalogue admission,
  exact identity/version selection, reference completeness and which source
  bytes remain authoritative when package metadata/schedule changes.
- Decide the minimum synthetic programme shape and editing operations after
  inspection. Avoid a new persisted Studio blob or executable export transport.
  Canonical YAML remains the authored representation; any reader text is derived.
- Retain the inherited non-green analysis baseline: fresh count/identity proof,
  zero errors, zero new/changed-file diagnostics, six safety groups and required
  compiler/Studio/reference/isolation/async regressions and visual Chrome review.
  Shared compiler/schema/hash, published artifacts and goldens remain protected.

No demonstrated hosted/external prerequisite is needed for allocating this
synthetic composition. If inspection reveals shared compiler/schema/hash changes
or broader authoring authority would be required, report the precise gap instead
of implementing it. Stable source binding/export coordination must be allocated
explicitly; D2's transient catalogue is not a cross-restart import/archive format.
